## Deskripsi Proyek

Proyek ini merupakan proyek praktikum Basis Data yang dikerjakan secara
individu dan dikembangkan secara bertahap dari Pertemuan 1 sampai Pertemuan
16. Proyek menggunakan basis data dengan tema Perpustakaan sesuai dengan
ketentuan tema berdasarkan dua digit terakhir NPM.

Proyek ini mencakup proses analisis kebutuhan data, pemodelan data,
normalisasi, pembuatan struktur basis data, pengolahan dan pengujian data,
pembuatan kueri, serta pengembangan dan dokumentasi basis data hingga proyek
akhir.

## Deskripsi Proyek

Proyek ini merupakan proyek praktikum Basis Data yang dikerjakan secara individu dan dikembangkan secara bertahap dari Pertemuan 1 sampai Pertemuan 16.

Proyek menggunakan tema **Sistem Informasi Perpustakaan** dengan nama basis data `perpus_009`. Tema proyek disesuaikan dengan ketentuan praktikum berdasarkan dua digit terakhir NPM.

Pengembangan proyek mencakup persiapan lingkungan basis data, analisis kebutuhan data, pemodelan data menggunakan ERD, normalisasi, pembuatan struktur basis data, pengolahan dan pengujian data, pembuatan kueri, serta dokumentasi proyek hingga tahap akhir.

## Teknologi dan Perangkat

Perangkat yang digunakan dalam pengerjaan proyek meliputi:

- DBMS MariaDB/MySQL sesuai lingkungan praktikum.
- Draw.io (diagrams.net) untuk membuat dan mengedit diagram ERD.
- Markdown untuk menyusun dokumentasi.
- Git dan GitHub untuk pengelolaan versi serta penyimpanan berkas proyek.

## Dokumentasi
